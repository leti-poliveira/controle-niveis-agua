# 💧 Controle de Níveis de Água

## 📌 Sobre o projeto

Este projeto foi desenvolvido para a atividade da Agenda 11 de Desenvolvimento de Sistemas I. O objetivo é simular o monitoramento de um reservatório de água, mostrando os níveis com mensagens coloridas no terminal.

## 📋 Funcionalidades

- 💧 Armazena cinco níveis de água em uma lista.
- 🎨 Utiliza cores diferentes para cada nível.
- ⚙️ Utiliza uma função para definir a cor da mensagem.
- 🖥️ Exibe os alertas no terminal.

## 🌈 Níveis do reservatório

| Nível | Situação | Cor |
|---|---|---|
| 1 | Muito baixo (crítico) | 🔴 Vermelho |
| 2 | Baixo | 🟡 Amarelo |
| 3 | Médio | 🟢 Verde |
| 4 | Alto | 🩵 Ciano |
| 5 | Muito alto (alerta) | 🔵 Azul |

## 🐍 Linguagem utilizada

Python.

## 🧮 Fórmula utilizada

O programa não utiliza fórmulas matemáticas. A cor da mensagem é definida de acordo com o número do nível do reservatório, utilizando estruturas condicionais (`if` e `elif`).

## ▶️ Como executar

1. Instale o Python no computador.
2. Instale a biblioteca Colorama pelo terminal:

   ```bash
   pip install colorama
   ```

3. Abra o arquivo `Leticia_Ag11_DSI.py` no VS Code.
4. Execute o programa no terminal.
